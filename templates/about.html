About This App

This is a sample website generated to demonstrate deployment on Azure App Service using Python 3.10.

Deploy with a simple git push via Azure deployment center, GitHub Actions, or ZIP deploy.

📂 Structure

  • app.py – application entry point
  • requirements.txt – Python dependencies
  • templates/ – Jinja2 HTML templates
  • static/ – CSS and static assets
